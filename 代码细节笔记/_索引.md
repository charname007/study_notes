- [[StarIR 的 StarModule 与 DFFN 实现]] — 论文式(2)–(8) 的张量对照：FMB/SMB 其实是共享投影再 split、star 前多一层 LayerNorm、DFFN 里 GEGLU 与窗口 FFT 是串行而非并行、CMU 池化在去模糊任务换成大核 AvgPool2d
- [[ConverseNet 的 Converse2D 算子实现]] — 官方 `cszn/ConverseNet@368aa39`：`Converse2D.forward` 逐行对应式(6)（`splits` 块平均=⇓s、`upsample` 填零=↑s、`p2o` 用 roll 消 PSF 偏心），`biaseps=sigmoid(bias-9)+eps` 即式(9) 的逐通道可学 λ；核 Softmax 初始化 + `assert in==out` 强制 depthwise；`ConverseBlock` 是 1×1 升 2C→GELU→Converse2D→GELU→1×1 压回 C 的双残差块（`LayerNorm` 为自定义 channels_first 版）；`ConverseUSRNet` 的 `ConvReverseDataNet` 把 KernelNet 嵌的 64 通道核当 K 直接喂式(6)。**最有料的差异**：论文 §5 称默认 5×5 核 / circular padding 4，而 `converse_dncnn.py` 实为 `kernel_size=7, padding=6`（Block 类默认又是 3×3/padding2/replicate），去模糊用 3×3；复现须以 released 模型文件为准
- [[Deformable DETR 的 MSDeformAttn 实现]] — 官方 `fundamentalvision/Deformable-DETR@11169a6`：论文 §4.1 的「一个 $3MK$ 通道投影」实际拆成两个 Linear（offset $2MLK$ + weight $MLK$，softmax 作用在最后一维 `n_levels*n_points` 上做跨层跨点归一化）；$\Delta p$ 的「无约束」靠 `offset_normalizer`（该层 W,H）折算成归一化坐标，4 维参考框时改成 `offsets/n_points * wh * 0.5`（对应附录 A.4 的框尺寸调制）；初始化 weight 全 0、bias 手动设成 8 方向单位向量并按第 $i$ 点 ×$(i+1)$ 拉长、attention 的 weight/bias 清零 → softmax 出 $1/(LK)$，即论文「初始注意力近似均匀」是**显式设计**而非巧合；真正的双线性采样在 CUDA 扩展 `MSDeformAttnFunction.apply`（im2col_step=64），CUDA kernel 未读

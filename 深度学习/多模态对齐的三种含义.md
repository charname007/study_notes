# 多模态「对齐」到底指三种不同的东西

> 读这批论文最容易混淆的一点：CLIP 说对齐、BLIP-2 说对齐、Flamingo 也说对齐，但三者讲的根本不是一回事。这篇把它们拆开。

## 三种对齐，一句话区分

| 类型 | 对齐什么 | 代表 | 判据 |
|---|---|---|---|
| **表示对齐**（representation） | 两个模态的**嵌入向量**在同一空间里距离近 | CLIP、ALIGN、SigLIP、ImageBind | 跨模态检索 R@1 高 |
| **融合对齐**（fusion） | 跨模态注意力**在每一层**把两路特征混起来之前，先让它们可比较 | ViLBERT、LXMERT、UNITER、ALBEF | VQA / NLVR2 等推理任务高 |
| **接口对齐**（interface） | 一边的表示能被**另一边的模型解码**，不要求同一空间 | BLIP-2、LLaVA、Flamingo | 生成质量、指令跟随 |

把这三者混为一谈，会导致一个典型误读：**「BLIP-2 比 CLIP 对齐得更好」是错的**——它们解决的不是同一个问题。BLIP-2 的 Q-Former 输出**并不**和 CLIP 文本嵌入在同一空间（它不是用来做检索的），它只是让 LLM 能读懂。

## 一、表示对齐：把两个模态塞进一个空间

**做法**：双塔，各自编码，投影到同维度，用对比损失拉近配对、推远非配对。

**关键判据**：跨模态检索。因为这个任务**直接就是**「在 N 个候选里找出配对的那个」，与训练目标同构（见 [[对比损失谱系 InfoNCE 到 Sigmoid]]）。

**这条线的代价**：双塔意味着两个模态之间**没有细粒度交互**。CLIP 无法回答「图中左边的猫是不是在椅子上」——那需要区域级推理，而双塔只产出全局向量。

这就是融合对齐要解决的问题。

## 二、融合对齐：先对齐，再让两路特征互相看

**ViLBERT / LXMERT / UNITER** 的做法：双流或单流 Transformer，图像区域特征和文本 token 在跨注意力层里互相 attend。它们的预训练任务里已经包含 ITM（图文匹配）——**这本质上就是一个对齐任务**，只是发生在融合层内部而非独立的双塔之间。

**ALBEF** 把这件事讲清楚了：如果直接融合，融合层要同时学「对齐」和「融合」两件事；先做 ITC 让单模态表示对齐，融合层就只负责融合。它的消融表里，加上 ITC 让 TR 从 93.96 → 96.55、IR 从 88.55 → 91.69（p.4）。

**这条线的代价**：需要区域级特征（Faster R-CNN）、架构重、推理慢。ViLT 之后去掉了区域监督，但仍需图文配对数据做跨模态编码。

## 三、接口对齐：不追求同空间，只追求「能读懂」

**BLIP-2** 的观察：既然图像塔和 LLM 都已经很强，为什么还要端到端重训？用 32 个可学习查询做信息瓶颈，把图像特征压成 LLM 能吃的 token 序列。

**LLaVA** 走得更直接：一个线性投影层把 CLIP 的 patch 特征映射到 LLM 的词嵌入空间，靠视觉指令数据微调。

**Flamingo** 又是另一种：冻结视觉塔和语言模型，中间插门控交叉注意力层（Perceiver Resampler + gated xattn-dense）。

**这三者的共同点**：都不要求图像嵌入和文本嵌入在同一个度量空间里可比较。它们只要求存在一个**可训练的翻译层**。所以它们不做检索，做的是生成和问答。

## 四、为什么这个区分重要

1. **选型时别选错目标**：要做图文检索，选 CLIP/SigLIP 这条线；要做 VQA/描述生成，选接口对齐这条线；要做细粒度视觉推理，选融合对齐。
2. **评测指标不可互换**：R@1 高不代表生成好，反之亦然。看到「某模型对齐更好」的说法，先问是哪种对齐、用什么指标量的。
3. **失败模式不同**：
   - 表示对齐失败 → 检索不到，但生成可能仍然可以（如果接了 LLM）；
   - 融合对齐失败 → 推理错，但全局检索可能还好；
   - 接口对齐失败 → 生成胡说，但底层 CLIP 嵌入其实是对的。

## 五、一个正在发生的收敛

2023 年之后，三条线在工程上开始合并：**SigLIP 做图像塔 + 一个投影/Q-Former 接 LLM**，已经是绝大多数开源 VLM 的标准配方（PaliGemma、Idefics、Qwen-VL 等）。也就是说：表示对齐用来**获得好的单模态表示**，接口对齐用来**把表示送进 LLM**，两者在同一系统里各司其职。

融合对齐反而在通用 VLM 里被弱化了——因为把跨模态融合交给 LLM 的注意力层去做，比专门设计融合层更省事。它现在主要活在需要精细空间推理的专用模型里。

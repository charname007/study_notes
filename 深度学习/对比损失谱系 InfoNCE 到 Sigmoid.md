# 对比损失谱系：InfoNCE 到 Sigmoid

> 这篇是把四条线索串起来的概念梳理：InfoNCE 怎么来的、SimCLR 的 NT-Xent 改了什么、CLIP 为什么用可学习温度、SigLIP 为什么换成 sigmoid。每条结论都对应到具体论文的页码。

## 一张表看完

| | InfoNCE (CPC 2018) | NT-Xent (SimCLR 2020) | CLIP (2021) | SigLIP (2023) |
|---|---|---|---|---|
| 归一化范围 | batch 内 N 个候选 | batch 内 N 个候选 | batch 内 N 个候选，**双向两次** | **无**，逐对独立 |
| 温度 | 隐含在 softmax 分母 | 显式 $\tau$，最优 0.5 | **可学习** $\log\tau$，需截断 | 固定值 |
| 负样本数 | = N | = batch-1 | = batch-1（双向） | 由负正比决定，与 batch 解耦 |
| 典型 batch | 小 | 4096 | 32768 | 32k 就够（可推到 1M） |
| 数值稳定 | 需减最大值 | 需减最大值 | 需减最大值 + 温度截断 | 天然有界 |

## 一、InfoNCE：从「预测未来」到「分类正负」

CPC（p.2–4）的原始动机是不要重建 $x_{t+k}$，只学密度比。损失是

$$\mathcal{L}_N=-\mathbb{E}\left[\log\frac{f_k(x_{t+k},c_t)}{\sum_{x_j\in X}f_k(x_j,c_t)}\right]$$

三个性质决定了后面所有演化：

1. **它是互信息的下界**：$I(x_{t+k};c)\ge \log N-\mathcal{L}_N$，且 $N$ 越大下界越紧（p.4）。→ **所有方法都想把负样本做多**。
2. **它就是分类交叉熵**：把正样本分到正确的类。→ 它继承交叉熵的一切性质，包括**对 batch 内归一化的依赖**。
3. **分母起温度作用**：负样本越多分母越大，正样本梯度越尖锐。→ 后来被显式参数化成 $\tau$。

## 二、NT-Xent：把温度显式化，把相似度归一化

SimCLR（p.6 表 2）的改动是技术性的但很关键：

- 相似度改成 **L2 归一化后的余弦**（有界，$[-1,1]$）；
- 温度 $\tau$ 显式提出来做超参；
- 结论：**两者缺一不可**（p.7 表 5）。不做 L2 归一化时，温度要补偿到 10/100 才勉强不掉，但对比准确率从 64.4 掉到 57.x。

消融还给了另一个结论：NT-Xent 63.9 > NT-Logistic 57.9 > Margin 57.5，且**不需要难负样本挖掘**。这是「softmax 式全负样本」对「采样负样本」的一次胜利。

## 三、CLIP：可学习温度 + 双向 + 超大 batch

CLIP（p.4–5）在三处做了工程化改动：

1. **双向**：行方向和列方向各做一次交叉熵。图像要找到它的文本，文本也要找到它的图像。单向只保证一个方向成立。
2. **可学习温度**：$\log \tau$ 作为参数学出来，但要**截断上界**以防训练不稳（p.5 伪代码注释 `# t - learned temperature parameter`）。
3. **32768 的 batch**：负样本数直接顶到显存允许的极限。这既是效果来源，也是复现门槛。

CLIP 把 InfoNCE 这条线推到了「必须多卡」的极端——于是下一个人要解决的问题就是**怎么把 batch 从损失里解放出来**。

## 四、SigLIP：去掉 batch 级归一化

SigLIP（p.1）指出的问题很直接：softmax 需要全局视野、需要大 batch、数值上还要靠减最大值稳定。

改成逐对 sigmoid：配对的对拉近（$\log\sigma(z)$），不配对的对推远（$\log\sigma(-z)$），**不做任何跨样本归一化**。

结果：

- 小 batch 下**显著优于** softmax（Fig. 2 左）；
- 大 batch 下两者趋同，**32k 就饱和**（Fig. 2 右）；
- 数值稳定天然解决（有界，不用减最大值）；
- batch 与损失解耦后，可以独立研究「样本数 / 配对数 / 负正比」。

## 五、这四条线在回答同一个问题的不同侧面

|| 问题 | 谁回答了 |
|---|---|---|
| 损失长什么样 | 怎么把「对齐」变成可优化的目标 | CPC |
| 怎么让损失好用 | 归一化 + 温度该怎么配 | SimCLR |
| 怎么让它规模上得去 | 负样本怎么变多 | MoCo（队列）/ CLIP（大 batch） |
| 怎么让它规模下得来 | 小 batch 还能不能训 | SigLIP |

**一条没有被任何一篇解决的遗留问题**：false negative。softmax 把所有非配对样本都当负样本，但其中可能混有语义相同的样本。ALBEF 用动量蒸馏的软目标缓解（[[ALBEF 先对齐后融合与动量蒸馏]]），但那是「减轻惩罚」，不是「识别并排除」。这是对比学习至今没被干净解决的问题。

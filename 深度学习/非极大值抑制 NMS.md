# 非极大值抑制（NMS）

## 是什么

非极大值抑制（Non-Maximum Suppression，NMS）是目标检测中的后处理步骤：从大量候选框中保留每个目标得分最高、位置最可信的框，并删除与这些框重叠过大的重复框。

## 为什么需要

检测模型通常会在同一个目标附近输出多个框。例如同一只猫可能出现多个高分类分数、位置相近的预测框。若全部保留，同一个物体会被重复检测。

NMS 的核心规则是：

> 按置信度从高到低挑选框；保留当前最高分框，删除与它重叠过大的其他框。

典型检测流程：

```text
检测网络输出候选框和类别分数
  ↓
过滤低分候选框
  ↓
NMS 删除重叠的重复框
  ↓
输出最终检测结果
```

## 怎么做 / 关键细节

### IoU：衡量两个框的重叠程度

IoU（Intersection over Union）等于两个框的交集面积除以并集面积：

$$
\operatorname{IoU}(A,B)
=
\frac{\operatorname{Area}(A \cap B)}
{\operatorname{Area}(A \cup B)}
$$

- IoU 越接近 0，两个框越不重叠。
- IoU 越接近 1，两个框越接近完全重合。
- NMS 用 IoU 判断一个候选框是否可能是在重复框同一个目标。

### 标准 NMS 的贪心流程

1. 按置信度从高到低排序所有候选框。
2. 取当前得分最高的框，加入最终保留集合。
3. 计算该框与剩余候选框的 IoU。
4. 删除 IoU 大于阈值的剩余框。
5. 在尚未删除的框中重复步骤 2–4，直到没有候选框。

伪代码：

```python
def nms(boxes, scores, iou_threshold):
    keep = []
    order = scores.argsort(descending=True)

    while len(order) > 0:
        i = order[0]
        keep.append(i)

        if len(order) == 1:
            break

        ious = compute_iou(boxes[i], boxes[order[1:]])
        order = order[1:][ious <= iou_threshold]

    return keep
```

以 `iou_threshold = 0.5` 为例：

- 框 A：0.95，保留。
- 框 B：0.92，与 A 的 IoU 为 0.85，删除。
- 框 C：0.88，与 A 的 IoU 为 0.20，保留。

### 阈值的影响

- 阈值较小，例如 `0.3`：抑制更严格，重复框更少，但相邻目标可能被误删。
- 阈值较大，例如 `0.7`：抑制更宽松，能保留密集目标，但更容易留下重复框。
- 常见初值在 `0.5` 左右，但最优值取决于模型、数据集和目标密集程度，不存在通用固定值。

### 类别相关与类别无关

- **类别相关 NMS**：每个类别分别执行 NMS。例如猫框只和猫框比较，狗框只和狗框比较。
- **类别无关 NMS**：所有类别一起参与重叠抑制。

多类别检测通常更常用类别相关 NMS；具体选择取决于检测框架和任务。

## 常见误区 / 注意事项

- **NMS 是后处理，不参与目标检测网络的梯度训练。** 它根据网络输出的框和分数执行筛选。
- **NMS 不只是“保留高分框”。** 它还依赖 IoU 判断候选框之间是否在描述同一个目标；置信度和重叠程度需要共同考虑。
- **IOU 阈值过小会伤害密集目标。** 人群、车辆或文本等场景中，两个真实目标本身就可能高度重叠。
- **NMS 也可能误删高 IoU 的真阳性。** DETR 相关观察表明，随着模型内部形成更强的重复预测抑制能力，额外 NMS 反而可能降低性能。
- **原始 NMS 的计算量会随候选框数量增长。** 实际框架通常先过滤低分框并限制候选数量。

## 常见改进方法

- **Soft-NMS**：不直接删除与高分框重叠较大的框，而是根据 IoU 降低其分数。
- **DIoU-NMS**：除 IoU 外，还考虑两个框中心点之间的距离。
- **旋转框 NMS**：用于遥感、文本检测等带角度的矩形框。
- **Score Voting / Weighted NMS**：融合多个重叠框的信息，而不是只保留一个框。

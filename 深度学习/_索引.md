# 深度学习 索引

## 概念笔记

- [[非极大值抑制 NMS]] — 目标检测后处理：按分数贪心保留框，用 IoU 删除重复预测；阈值取舍、类别相关 NMS 与常见变体
- [[通道注意力]] — 按输入内容给特征通道分配权重；整理 GAP+MLP、一维卷积、双池化、二阶统计、频域、多分支、坐标感知与通道协方差等形式
- [[能量概念]] — 区分信号/特征能量、正交小波的总能量守恒、优化代价能量与 EBM 低能量概率；重点说明“总能量不变”不等于每个频带不变
- [[文本聚焦损失]] — STISR 中让超分图同时对齐字符注意力、识别内容和字符混淆关系的任务级损失；需与 Focal Loss 区分
- [[像素重排：PixelUnshuffle 与 PixelShuffle]] — 无参重采样，空间↔通道重排，Restormer 降/升采样用的算子
- [[PointWise和DepthWise]] — 1×1 与 depthwise 卷积的分工与排布
- [[Transformer Decoder 中 self-attention 与 cross-attention 的顺序]] — self-first、cross-first、并行 attention 与 Norm/mask 注意事项
- [[transformer的2道残差连接]] — Attention / FFN 各一道残差的必要性
- [[各种Norm层的摆放]] — Pre-LN / Post-LN 等
- [[各种初始化方式]]
- [[齐次坐标变换]]
- [[浅层与深层]]
- [[未命名]]
- [[曝光偏差 Exposure Bias]] — teacher forcing 造成的训练/推理前缀分布错位；含误差累积、缓解谱系（Scheduled Sampling / DAgger / MIXER / Professor Forcing）、「它是否被夸大」的正反实证，以及**自回归是否必然受此影响 / 大模型如何用 on-policy 后训练与扩散范式应对**
- [[低分辨率文本图像的编码器选型]] — 核心矛盾是**信息本来就少、下采样再丢一次**，所以首要原则是**控制空间压缩比而非堆深度**：SVTR 式 patch embedding + **三阶段只压高度不压宽度**（$H$ 压到 1/4 而非 1/16）最适合文本；SVTRv2 进一步把特征高度从 $H/16$ 翻倍到 $H/8$，并用 **MSR 按宽高比分四档 resize**（强行 32×128 会让窄文本严重形变，第一档 +15.3%）；HRNet 全程保留高分辨率（无池化、多分支并行交换）但代价大；TATT 式 Transformer 解决的是**全局关联**（卷积抓不住旋转/弯曲的大位置偏移），代价是复杂度随文本长度增长；TATSR 用**十字交叉注意力**沿行列建模作折中（文本长程依赖主要在水平方向）；TSRN 的 **SRB（BLSTM 残差块）**用水平+垂直双方向建模序列依赖；含决策表与四条原则（别强行统一 resize、长程依赖沿水平、编码器要能被文本先验查询）
- [[PSNR 与 SSIM 图像质量指标]] — 全参考指标两件套：**PSNR 只看「差多少」**（$\mathrm{PSNR}=10\log_{10}(\mathrm{MAX}^2/\mathrm{MSE})$，8bit 图 30–50dB，>40dB 肉眼难辨），**SSIM 还看「差在哪」**（拆成亮度 $l$ / 对比度 $c$ / 结构 $s$ 三项，$\mathrm{SSIM}=\frac{(2\mu_x\mu_y+C_1)(2\sigma_{xy}+C_2)}{(\mu_x^2+\mu_y^2+C_1)(\sigma_x^2+\sigma_y^2+C_2)}$，$K_1{=}0.01,K_2{=}0.03$，$11\times11$ 高斯窗）；解释**为什么两者会给相反排序**（过度平滑让 MSE 小、PSNR 高，但结构丢了）；并指出在 STISR 领域这两个指标**对字符级错误不敏感**（GLYPH-SR、Reading the Unreadable 实证 PSNR/SSIM 与文本复原质量无正相关），文本任务必须看识别率
- [[特征融合方法谱系]] — 从「拼接 / 相加」往上排表达力：**拼接本身无参数、后接线性层在数学上退化成「各自加权求和」**（$W[h_A;h_B]=W_Ah_A+W_Bh_B$），交互只在后续非线性里产生；逐元素乘只能对齐同下标；真正能表达全两两交互的是**外积/双线性**（MCB 证明外积 > 逐元素乘/和/拼接，CBP 用随机投影降维，MFB 低秩分解，**LMF 把张量融合从模态数指数增长降到线性**）；另有**门控**（按样本决定信谁、能抗模态缺失）、**调制**（$z=\gamma(h_B)\odot h_A+\beta(h_B)$，每通道 2 个标量）、**cross-attention**（A 的每个位置去 B 里选不同的东西，$O(N_AN_B)$）与**联合注意力**（是 self-attention 与 cross-attention 按 softmax 归一化常数加权混合，二者可互表）；含选型表与六条误区（拼接参数陷阱、门控≠注意力、双线性是近似/有损、模态缺失时晚期融合更稳）
- [[调制 Modulation]] — 用条件信号生成 scale/shift 去重分配特征增益；FiLM → AdaIN → SPADE → adaLN-Zero 谱系、与注意力的分工（全局倾向 vs 局部绑定）、以及 AdaIN 全局性 / 水滴伪影 / adaLN 装不下长 prompt 的三类批评

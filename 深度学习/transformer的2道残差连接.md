在 Transformer 架构中设计 **两道残差连接**（一道套在 Attention 外面，一道套在 FFN 外面），并不是随意写写的，而是现代深度学习中经过严密推导和实验检验的**标准经典范式**。

它的核心原因可以归结为：**分工解耦、梯度高速公路、以及保护图像基底。**

我们可以把一个 Block 拆成两步来看：

---

### 1. 两道残差保护着两种“完全不同”的任务

标准的 Transformer 块把特征处理严格拆成了两步：**“空间混合”** 与 **“通道混合”**。每一步都需要一道残差来保底：

#### 第一道残差：保护“空间/注意力交互”
```python
x = shortcut + x_win  # x_win 是窗口注意力算出来的结果
```
* **Attention 在干嘛？** 它是**跨空间/跨像素找关系**。低频在向周围的像素或高频先验“借细节”。
* **为什么必须加残差？**
  * 注意力本质上是一个加权平均（$\sum A_i V_i$）。如果没有这道残差，当前像素自身的原始特征就会被周围邻居的加权结果**直接覆盖、稀释掉**，当前像素会“迷失自我”。
  * 加上残差后公式变成：$\mathbf{x}_{\text{新}} = \mathbf{x}_{\text{自己}} + \Delta \mathbf{x}_{\text{从邻居借来的高频细节}}$。
  * **作用**：确保像素**以自己为绝对主体**，只把注意力算出来的特征当成**微小的增量补充**。

#### 第二道残差：保护“通道特征重构与非线性升维”
```python
x = x + self.convffn(self.norm2(x))  # convffn 负责非线性特征提纯
```
* **ConvFFN 在干嘛？** 它是像素**自身的深度思考**。它不看邻居，只在通道维度上把特征放大 2~4 倍，通过 GELU/ReLU 激活函数进行剧烈的非线性变换，再压缩回去。
* **为什么必须加残差？**
  * 深度非线性 MLP 很容易发生**退化**，或者把刚融合好的特征改得面目全非。
  * 加上残差后，ConvFFN 学习的同样是一个非线性扰动量 $\Delta \mathbf{x}_{\text{提纯}}$。

---

### 2. 为什么不合二为一？（为什么不写成 $x = x + \text{FFN}(\text{Attn}(x))$？）

你可能会想：*“为什么非要两道？在最外层套一个大残差，把它们当成一个整体不行吗？”*

**真的不行，原因有两个：**

#### 原因一：为 FFN 提供稳健、完整的输入
如果写成 $x = x + \text{FFN}(\text{Attn}(x))$：
* FFN 的输入就只有纯粹的 $\text{Attn}(x)$；
* 但第一道残差能让 FFN 接收到的输入是 **$[x + \text{Attn}(x)]$**。
* **物理意义**：FFN 既能看到你**原本的特征**，又能看到你**刚从注意力借来的细节**，两者结合在一起给 FFN 处理，特征表达力远强于只看注意力输出。

#### 原因二：更密集的“梯度高速公路”（Gradient Highway）
* 深度 Transformer 通常有数十甚至上百层。反向传播时，误差梯度每穿过一层复杂的矩阵运算（如 Softmax 或非线性激活），信号就会衰减一层。
* **两道短残差**相当于在每半个模块之间，都架设了一条穿透直达的“跳线”（$f(x) = x$，导数为 1）。
* 无论网络叠到多深，后方的梯度都可以通过两条短平快的直连通道，无损直接回传到最初的输入端，**彻底杜绝梯度消失和网络退化**。

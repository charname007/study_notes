# BLIP-2：用 32 个查询把冻结的图像塔与冻结的 LLM 接起来

> Junnan Li, Dongxu Li, Silvio Savarese, Steven Hoi（Salesforce Research）。页码指本机 PDF 页码。

## 一句话总结

两端的模型都**冻结不动**，中间插一个只有 188M 参数的 **Q-Former**，用 32 个可学习查询去榨取图像塔里对文本有用的信息，再喂给 LLM。分两阶段预训练：先学视觉-语言表征（ITC/ITM/ITG），再学视觉到语言的生成。在零样本 VQAv2 上比 Flamingo 高 **8.7%**，而**可训练参数少 54 倍**。

## 要点提炼（速览）
1. **核心痛点**（p.1）：当时 SOTA 的视觉语言模型预训练代价极高，因为要**端到端**训练大模型 + 大数据集。BLIP-2 的想法是：既然单模态模型都已经很强了，为什么不冻结它们、只训练一个轻量的桥？
2. **Q-Former**（p.2–3）：由两个子模块组成，共享同一套自注意力层——(a) 图像 transformer，与冻结的图像塔交互；(b) 文本 transformer，可与文本交互。**32 个查询**，每个 768 维（p.3），总计 **188M** 参数，用 BERT-base 初始化，跨注意力层随机初始化。
3. **查询是模型参数**（p.3 原文）：这些 query 不是从图像里来的，而是**学出来的固定参数**，它们通过跨注意力把图像特征压缩成固定数量的向量。这就是它能桥接任意图像塔的原因。
4. **第一阶段：视觉-语言表征学习**（p.2）。三个目标同时训练 Q-Former，但用**不同的自注意力掩码**控制查询与文本能怎么交互：ITC（对比）、ITM（匹配）、ITG（基于图像的文本生成）。
5. **第二阶段：视觉到语言生成学习**（p.2, p.4, Fig. 3）：把 Q-Former 的输出经全连接层接到**冻结的 LLM**，训练 Q-Former 让它的输出能被 LLM 读懂。对 decoder 型 LLM 用后缀文本，对 encoder-decoder 型（如 FlanT5）用前缀文本。
6. **结果**（p.1, p.6–7）：零样本 VQAv2 比 Flamingo 高 **8.7%**，且可训练参数少 **54×**；在零样本文本生成（NoCaps）、图文检索上也具竞争力。
7. **为什么省**：图像塔和 LLM 都冻结，训练时只需更新 Q-Former 的 188M 参数，显存和算力需求大幅下降。
## 核心问题

到 2022 年，视觉和语言两边都各自有了强大的预训练模型（ViT、CLIP 图像塔；OPT、FlanT5 等 LLM）。但把它们拼起来做多模态时，主流做法是**端到端联合训练**，代价随模型规模快速上升。

所以真正的问题是：**能不能不动两端的权重，只学一个轻量模块，把已经很强的单模态表示翻译成对方能用的形式？**

这个问题难点在于：图像塔输出的是密集的 patch 特征，LLM 输入的是离散 token 序列，两者的接口形状完全不同。Q-Former 就是为这个接口设计的。

## 关键方法

### 1. 查询作为信息瓶颈

固定 32 个查询去读图像特征，意味着无论图像分辨率多高、patch 有多少，输出永远是 32×768。这既大幅降低了送进 LLM 的 token 数，也强迫 Q-Former 只保留与文本相关的信息。它是一个**有损但定向的压缩**。

### 2. 两阶段的意义

- **第一阶段**让 Q-Former 学会提取什么——通过 ITC/ITM 学对齐、通过 ITG 学生成；
- **第二阶段**让 Q-Former 学会怎么表达给 LLM 听——此时图像塔和 LLM 都冻结，只有 Q-Former 在学如何把自己的输出校准到 LLM 的语义空间。

分两阶段而不是一起训，是因为第一阶段的目标（对齐）和第二阶段的目标（可被 LLM 解码）会互相干扰。

### 3. 掩码控制多任务

同一套查询，通过切换自注意力掩码实现三种交互模式：查询之间可见/不可见、查询与文本可见/不可见。这样三个目标可以共享参数而不互相泄漏。
## 结论与局限

**贡献**：把多模态对齐问题重新表述成接口设计问题——不需要两个模态的表示在同一个空间里精确对齐（那是 CLIP 的做法），只需要一个模块能把一边的表示翻译成另一边能用的东西。这条路线直接定义了后来 InstructBLIP、MiniGPT-4、LLaVA 等一系列工作的问题框架。

**局限 / 值得注意的点**：

- **32 个查询是强信息瓶颈**。对需要细粒度空间信息的任务（密集描述、OCR、小目标检测）天然不利。后续工作有把查询数调大或改用其他接口的。
- **冻结图像塔意味着无法针对下游改进视觉侧**。如果图像塔本身漏掉了关键信息，Q-Former 补不回来。
- **两阶段训练流程复杂**，超参多，复现成本不低。
- **它的对齐是单向的**：只保证视觉信息能被 LLM 读懂，不保证 LLM 的语义反过来对齐到视觉。这跟 CLIP 的双向对比对齐是两种不同意义上的 align。

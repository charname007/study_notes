# SimCLR：拆开对比学习，逐个消融四个部件

> Ting Chen, Simon Kornblith, Mohammad Norouzi, Geoffrey Hinton（Google Research, Brain Team）。页码指本机 PDF 页码（正文 14 页 + 附录）。

## 一句话总结

不需要特殊架构、不需要 memory bank——一个简单框架（强增广 + 非线性投影头 + 大 batch + NT-Xent）就能超过此前的自监督方法。ImageNet 线性分类 **76.5% top-1**，相对提升 7%，追平监督 ResNet-50；只用 1% 标签微调时 top-5 达 **85.8%**。这篇真正的价值在于**把对比学习拆成四个可独立消融的部件**，并证明增广组合是其中最关键的。

## 要点提炼（速览）

1. **框架极简**（p.3, Algorithm 1）：同一张图做两次随机增广得 $\tilde x_i, \tilde x_j$ → 同一编码器 $f$ 出 $h$ → 小 MLP $g$ 投影到 $z$ → 在 $z$ 上算 NT-Xent。下游只用 $h$，丢掉 $g$。
2. **NT-Xent**（p.6 表 2）：$\ell_{i,j}=-\log\frac{\exp(\mathrm{sim}(z_i,z_j)/\tau)}{\sum_{k\neq i}\exp(\mathrm{sim}(z_i,z_k)/\tau)}$，相似度是 **L2 归一化后的余弦**。附录补充：训练收敛后最优温度在 $\{0.1,0.5,1.0\}$ 里稳定取 **0.5**，但小 batch 下更偏好 0.1。
3. **增广组合是头号功臣**：单独一种增广都不够，**随机裁剪 + 随机颜色失真**这一组合明显最好。作者的关键论断是：没有一种单一增广能同时定义出好的预测任务，必须靠组合。
4. **高斯模糊的量化贡献**（p.13）：加进默认策略后，100 epochs 下 ResNet-50 从 63.2% → 64.5%。
5. **投影头必须非线性**（p.6）：$g$ 用 ReLU 比线性好很多；而且**下游用 $h$ 不用 $z$**——$z$ 上丢掉的正是对比任务有用、对下游无用的信息。这个「表示与损失解耦」的发现后来成了标配。
6. **大 batch + 长训练**（p.3 与附录一致）：默认 **batch 4096**、100 epochs。结论是对比学习比监督学习**更吃 batch size 和训练步数**。
7. **损失函数对比**（p.7 表 4）：NT-Xent **63.9** / NT-Logistic 57.9 / Margin（含半难负样本挖掘）**57.5**——NT-Xent 胜出，且**不需要难负样本挖掘**。
8. **L2 归一化 + 温度缺一不可**（p.7 表 5）：不做 L2 归一化时，温度要补偿到 10 / 100 才勉强不掉，但对比准确率明显低（57.2 / 57.0 vs 64.4）。

## 核心问题

2019 年前后的对比学习方法（InstDis、CMC、MoCo、PIRL 等）各带一套额外组件：memory bank、队列、特殊感受野设计。两个问题因此没被回答：

1. **这些组件里哪些是必要的？** 去掉它们还成立吗？
2. **对比学习到底靠什么学到表示？** 是损失？是架构？还是别的什么？

SimCLR 的答案是：**都不是，是增广**。它用一个刻意简化的框架做控制变量，把「哪一步在起作用」摊开。

## 关键方法

### 1. 增广组合（本文最值钱的结论）

对比学习的正样本对 = 同一张图的两种视角。所以**增广定义了「什么该被视作同一个东西」**，也就定义了任务本身。作者发现：

- 单种增广效果都有限；
- **随机裁剪 + 随机颜色失真是最强组合**；
- 加入高斯模糊有小幅提升（63.2 → 64.5）；
- 「颜色失真」这一项在别的框架里常被省掉，而它在这里是必需的。

### 2. 非线性投影头（表示与损失解耦）

$z = g(h) = W_2\,\sigma(W_1 h)$。在 $z$ 上算对比损失，下游用 $h$。消融显示 $g$ 非线性优于线性，且**去掉 $g$ 直接拿 $h$ 算损失会显著掉点**。解释是：对比任务需要保留一些对下游无用的信息（如颜色直方图），$g$ 提供了可丢弃的缓冲区。

### 3. 大 batch 与长训练

batch 越大，NT-Xent 的负样本越多，任务越难也越有信息量。默认 4096，且发现对比学习从更多训练步数中获益比监督学习更大。

### 4. 余弦相似度 + 可调温度

L2 归一化后算余弦，再除以 $\tau$。表 5 说明两者缺一不可——归一化把相似度压到有界区间，温度控制 softmax 的尖锐程度。

## 结论与局限

**贡献**：把对比学习从「一堆各带私货的方法」收敛成一个可分析的框架，并给出可复用的设计清单（强增广、非线性头、大 batch、余弦 + 温度）。76.5% 追平监督 ResNet-50 是当时的标志性结果。

**局限 / 值得注意的点**：

- **4096 的 batch 是硬门槛**。本篇结论几乎全部建立在大 batch 上；SigLIP 的核心动机之一就是小 batch 下 softmax 对比损失不划算（见 [[SigLIP 用 Sigmoid 损失解耦批大小]]）。复现时若 batch 上不去，很多结论不成立。
- **对增广的依赖是双刃剑**。方法在自然图像上成立，换到医学影像、文本等「颜色 / 裁剪无意义」的模态时需要重设计增广——这正是 [[ConVIRT 医学图文对比学习]] 这类工作报告的事。
- **没有解决负样本质量问题**。NT-Xent 把所有非配对样本当负样本，其中可能混有语义相同的样本（false negative），本文未处理。
- **76.5% 仍低于同规模监督**：附录里自监督 ResNet-50 (4×) 是 76.5%，对应监督版本 78.3%。

# LLaVA：一个线性投影 + 视觉指令数据
> Haotian Liu, Chunyuan Li, Qingyang Wu, Yong Jae Lee（威斯康星麦迪逊 + 微软研究院 + 哥伦比亚）。页码指本机 PDF 页码。

## 一句话总结

用**纯语言的 GPT-4** 生成多模态指令跟随数据（把图片转成文本描述 + 框坐标喂给 GPT-4），再用这些数据微调一个「CLIP 视觉编码器 + 线性投影 + Vicuna」的模型。作品首次尝试用语言模型生成多模态指令数据，并在 Science QA 上达到当时 SOTA。

## 要点提炼（速览）

1. **接口极简**（p.2）：CLIP 的开放集视觉编码器 → **一个线性投影** → Vicuna 词嵌入空间。端到端微调。没有 Q-Former，没有门控交叉注意力，就一层线性层。

2. **数据怎么来**（p.1）：把图像转成 GPT-4 能读的文本表示（描述 + 物体框），让 GPT-4 生成对话、细粒度描述、复杂推理三类指令数据。

3. **结果**：与 GPT-4 集成后在 Science QA 上达到 SOTA（p.2）。

4. **方法论意义**：它证明**接 LLM 不一定要复杂的桥**。BLIP-2 用 32 个查询做瓶颈，LLaVA 用一层线性投影，两者都工作——说明关键在于**训练数据与目标**，而不是接口的复杂度。

## 为什么值得在多模态对齐的主题里读

它是 [[多模态对齐的三种含义]] 里「接口对齐」这条线的最简实现。有意思的对比：

| | BLIP-2 | LLaVA |
|---|---|---|
| 接口 | 32 查询 + Q-Former（188M） | 一层线性投影 |
| 训练 | 两阶段，两端冻结 | 端到端微调 |
| 数据 | 图文对（预训练语料） | GPT-4 生成的指令数据 |
| 代价 | 便宜（不训大模型） | 贵（要微调 LLM） |

这个对比说明：**接口复杂度与训练数据量之间存在权衡**。数据贵则接口要简单（LLaVA），数据便宜则接口可以复杂（BLIP-2）。

## 局限

- 依赖 GPT-4 造数据，成本与可复现性受限于闭源模型。

- 线性投影对细粒度空间信息的保留能力弱（与 BLIP-2 的查询瓶颈是同类问题的不同侧面）。

- 论文重点是「这套流程能work」，对失败模式的分析较少。

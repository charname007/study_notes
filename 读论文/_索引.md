# 读论文 索引

## 论文笔记

- [[DVAR 动态视觉自回归单图超分]] — CVPR'26（南理工 PCA Lab + 南大）：把 VAR 的 next-scale prediction 从「每个分辨率背一套绝对缩放序列」改成**一条典范尺度序列按比例缩放**（canonical scaling dynamic，式 5，基准 256²、序列 1,2,3,4,5,6,8,10,13,16），并用 **LQ 导出的动态起始 token map** 取代固定 1×1 start token（复原是 refinement task，LQ 自带结构先验），再叠尺寸专属注意力掩码 + 目标尺寸嵌入；另用 **DSS** 缓解 exposure bias——利用 VQ 码本的几何邻近性，为每个尺度维护 count book（rank 分布，EMA 更新），按它从 GT 的 k-NN 里采样「模拟误差」注入训练，零额外前向。CLIPIQA / MANIQA 三 benchmark 全 SOTA（DIV2K-Val 0.7405/0.5641、RealSR 0.7050/0.5756、DRealSR 0.7351/0.5653），MUSIQ 第二；**但 PSNR/SSIM 明显偏低**（VQ tokenization error，作者自认，perception–distortion 权衡）。消融最有料：只在 512² 训练、无尺寸条件的变体就零样本超过 VARSR（0.7531 vs 0.7477 CLIPIQA），完整 DVAR 到 0.7767；DSS 全指标一致涨（DIV2K-Val CLIPIQA 0.7152→0.7405）。局限：训练代码未开源、消融只在 RealLR200 且长边缩到 512、未报同口径推理耗时
- [[RetFormer 多模态检索增强图像识别]] — CVPR'26（浙大）：不把世界知识压进权重，外挂约 1.4B 图文对知识库（DataComp xlarge / All），查图经冻结 CLIP ViT-B/16 得嵌入后 k-NN 取 top-k 邻居，再用**检索交叉融合模块**（文本 Q 查图像 K/V、图像 Q 查文本 K/V 的交叉注意力 + 各自残差，L=4）算贡献，与 MLP 主干分支按 τ/2 合并出 logits；半参数、不显著增算力。ImageNet-LT **81.9%**、Places-LT 52.3、iNaturalist 81.1、WebVision 81.7/77.3 均 SOTA。**消融最有料**：去文本掉到 76.0、去图像 78.1（文本更值钱）；k 升到 32 后稳定但 Many-shot 反降（大 k 引入噪声标签）；知识库越大尾类涨幅最大；L=4→8 仅 +0.11%；HNSW recall 0.97 时 23.34→7.69 ms 且精度几乎不掉（约 3× 加速）。梯度视角把检索邻居解释为「虚拟样本 / 数据依赖增强」，故尾类受益最大。**局限自曝**：Places-LT 场景分类 vs 知识库文本偏物体导致图文失配、检索或过度校正（试了 k=8,16）；需额外约 30GB 存储、编码器冻结不可端到端更新、训练总开销未报
- [[TiGeSR 先文本后图像的两阶段场景文本超分]] — CVPR'26（南开 PCA Lab + vivo）：把「字形恢复」与「整图增强」解耦成两阶段（text-first, image-later）——Stage 1 扩散式文本修复器在文本区域恢复笔画、拼成文本掩码（两阶段训练：Phase1 合成+真实混训学真实退化 / Phase2 冻结输出块只用合成精修，MSE+Focal+Dice 掩码损失）；Stage 2 把掩码当 ControlNet 条件注入 SD3.5 单步去噪（$\hat z_H=z_L-\sigma_t\epsilon_\phi$），配 MSE+LPIPS+Sobel 边缘损失；另提 UZ-ST（vivo X200 Ultra 四焦距 14/35/85/200mm、最大 ×14.29、5,036 对 / 49,675 行、级联由粗到细对齐）；Real-CE PSNR 24.12 / SSIM 0.839 / OCR-A **67.3%**、UZ-ST 25.48 / **43.0%** 全面超 TADiSR(64.7/36.6)，且是唯一 OCR-A 相对 LR 不降反升的方法（+2.5%/+1.3%）；消融：空掩码 59.5% / 标准字体 55.3% / SAM-TS 57.9% / LDM 60.1% → 本方法 67.3%（掩码质量贡献最大），换空/随机 OCR 文本仍 40.4%/40.3%（不过度依赖 OCR），UZ-ST 微调让 OSEDiff/DiT4SR OCR-A 22.8→28.9 / 19.3→23.7；局限：SD3.5 + tile 推理开销未系统报告、仅 Real-CE + 自建 UZ-ST 两个 benchmark
- [[PRISM 语言引导原型学习的可解释图像识别]] — CVPR'26（南大）：不换 ProtoPNet 骨架，改用 CLIP 文本支路 + 图文信息瓶颈（把 $I(\tilde X;Z)-\beta I(\tilde X;X)$ 的 $Y$ 换成文本嵌入 $Z$，注噪式 IBA 学归因矩阵 $A$）在**推理期之外**算一张类名条件归因图 $\mathcal{A}$，用 $\ell_1$ 让类内原型激活图之和逼近它（$\mathcal{L}_{align}$），再加一条**空间熵约束** $\mathcal{L}_{comp}$（原型维 softmax 后算熵）逼同类原型别抢同一块像素；CUB-200-2011 ViT-B/16 **87.8%**、Dogs 86.1%，比 ProtoPNet +2.3~+4.6，甚至比不可解释基线平均高 +0.9；一致性 75.75% vs ProtoPNet 19.85%（1.6×~3.8×），Deletion AUC 7.84 / Insertion 77.67 / IoU 46.32 / OIRR 26.41 全面领先；**但消融自曝**：只用 $\mathcal{L}_{align}$ 时一致性 96.3、稳定性 77.5 全表最好，加上 $\mathcal{L}_{comp}$ 反而回落到 75.8 / 66.5（换来语义可区分性），且只加 $\mathcal{L}_{comp}$ 精度还掉（82.2→80.2）；稳定性 ViT-B/32 上 69.71% 略低于 ProtoPNet 70.34%；只测 CUB/Dogs 两个细粒度集、文本侧只用类名、训练开销全篇未报
- [[TPWGAN 小波域判别器引导的场景文本超分]] — IVC 2025：不改主干、只改「监督放在哪」——生成器加平稳小波（SWT）四子带加权 $L_1$（$\lambda_{LL}$=0.1、$\lambda_{LH/HL}$=0.01、$\lambda_{HH}$=0.05），判别器丢掉 RGB 图、改看「三支高频子带 ⊗ 二值文本掩码」的 4 通道输入 + CBAM 式空间注意力，Softplus 对抗损失；TextZoom PSNR 21.70 / SSIM 0.7965 / ASTER 64.4%，超过基线 TATT（21.52/0.7930/63.6）与 DPMN（21.49/63.9），但 CRNN 53.1 仍输 DPMN 53.2、CUTE80 输 TSRN；消融：小波损失是便宜稳定的一档（Easy ACC 76.7→78.51），对抗在 Hard 最猛（+1.6），**掩码贡献最小甚至 Medium PSNR 微降**，且不做注意力直接 concat 掩码反而更差（Hard 44.9 < 45.6）；局限：字/背景边界模糊时小波监督失效
- [[C3-STISR 三重线索引导的场景文本超分]] — arXiv'22（复旦 + 字节，ICME 前身线）：诊断出「只用识别器概率分布」的两个硬伤——模态鸿沟（PD vs 像素级任务）与不准确（LR/HR 识别率仅 26.8%/72.4%）；于是把线索扩成三条：识别 PD、**把识别串渲染成黑白字形图**当视觉线索、**字符级双向 cloze LM（SRN）**纠错当语言线索，各自投影成 $C'\times N$ 像素特征后 DSTA 去噪、门控融合成 $h_t$ 逐层灌进 5 个 TSRN block；TextZoom CRNN avg **53.7**（前最佳 TG 48.9，+4.8）、ASTER 64.1、PSNR 21.51/SSIM 0.7721；消融：deformable 对齐补偿贡献最大（49.4→51.7），MST +2.6、DSTA +2.0；**但三线索的识别率增益为零**（rec+ling 已 53.7，加 vis 仍是 53.7，只在 PSNR 上 +0.23），且 SSIM 反而低于 PCAN（77.53）
- [[LWTformer 可学习小波变换的古汉字图像修复]] — 把 2D-DWT 做成可学习下采样（WaveDown，可学习低通/高通核拆出轮廓 + 水平/垂直/对角三支高频），配 SEA 空间门控（MDTA 增量改进）与 WACGA 子带方向加权（Prewitt/Laplacian 类核）；甲骨文与 WSC41K 四项指标全 SOTA，轻量版 12.44M 参数打赢 50M 级 LoFormer-L；消融：WACGA 贡献最大 +0.225 dB，去掉感知损失 PSNR 反而更高
- [[RDA 残差解码适配器 保持ID的自回归文字渲染]] — CVPR'26（中南大学 + 牛津 + MSRA）：把 AR 文字渲染「笔画糊/字形歪」的根因定位到 VQ tokenizer 的量化重建，提出**免重训**的 Residual Decoder Adapter——基础分词器全冻结，新增**共享同一 token ID 的 Hint Codebook**（$f_{base}=z_i$、$f_{hint}=z'_i$，式 3）+ 并行残差解码器在像素空间学 $\Delta I=I-\hat I$，注入 $f_{mix}=p(f_{base})+q(f_{hint})$ 后 $\hat I_{final}=\hat I+D_{res}(f_{mix})$（式 4–6）；因码本冻结、ID 分布不变，AR 模型即插即用、一行都不用重训。text-specific Janus-Pro 1B 在 StyledTextVisionBlend OCR Acc **24.52→58.26**（+33.74）、StyledTextSynth 12.75→36.81；只用 5M 图（UniTok 用 1.28B）、256px 训练即泛化到 1024px。消融三处最有料：**残差感知损失 $L^{res}_{perc}$ 是命门**（去掉 66.48→58.30 退回 baseline 58.04，训练直接失败）；hint 维度 **16 最优、32 反而回落**；**不做 base 特征注入比 baseline 还差**，而 Add/Cross-Attn/Concat+Conv 差别很小。训练难在稀疏残差被背景淹没，故叠 $L_{rec}+L^{final}_{perc}+L^{res}_{perc}+L_{sobel}+L_{freq}$（式 10）。OOD：直接微调 decoder 让 ImageNet FID 9.63→14.75 且过平滑，RDA 只到 11.20。局限：免重训的是 AR，RDA 自身仍要 64×V100/120k steps；评测几乎只压 OCR 指标；对「token 预测错」的语义层无能为力（双瓶颈解释）

- [[DTWSR 扩散Transformer建模多级小波谱的单图超分]] — 三星 SRCX：把整条扩散去噪链搬进小波谱域（每个采样步 MDWT→谱域去噪→IMDWT），金字塔 tokenization（$p^j=p_{min}2^{J-j}$，token 1040→704）+ 4D 位置编码 + 双解码器（LEDec 管 LF 主体、HDDec 管多级 HF 与 LF 残差，配 $M_{low}/M_{high}$ 两个互斥掩码）；8× 人脸 Cons. 0.50 / Deg. 53.85 / FID 56.77 三项最优（PSNR 24.09 不及 WFEN 的 25.53，但那版输出过平滑），RealSR 上 MUSIQ 64.04 最高；消融关键：双解码器单独拆开 Cons. 反而变差（2.35），必须配 LF 残差才回到 0.549，再加 $M_{high}$ 才到 0.503；切断 HF 子带交互 FID 56.77→61.67，印证核心动机
- [[PFT 渐进聚焦 Transformer 单图超分]] — 相邻层注意力图做 Hadamard 乘积并逐行归一化（连乘自然稀疏），再把结果当 0/1 索引**先选后算**跳过相似度计算：Urban100 ×4 +0.36dB 且 FLOPs −27.7%，撑起 32×32 大窗口；消融证明"继承买精度、聚焦买速度"
- [[HDW-SR 小波高频引导扩散的单图超分]] — SRCX 2026（CVPR 2026）：残差扩散 + **Haar 小波当上下采样**替换 U-Net 池化，用 PreSR 的高频子带（LH/HL/HH）当 K/V、与噪声图低频做稀疏交叉注意力（DFA，继承 PFT 的层间索引）；DTB 把 Top-k 换成 Otsu 类间方差定 $k^*$；DIV2K/RealSR/DrealSR 上 LPIPS、DISTS、MUSIQ 基本全胜，但 **PSNR 略低于 ResShift**；消融：去掉高频引导 −3.56 dB、先验换成 HA-Net 自身 −1.32 dB、DWT 换回 CNN −0.55 dB；DTB 同时省 22% FLOPs
- [[StarIR 空间-频率融合的卷积图像复原]] — 纯卷积 encoder-decoder：FMB（8×8 窗口 FFT + 可学习频响）⊗ SMB（空间注意力）做 star 相乘融合 + CMU 通道调制；21 数据集 6 类单退化 SOTA，五任务一体化平均 +0.96 dB，CDD-11 三退化 +2.89 dB 且参数少 41%；消融显示 SMB/FMB 单加仅 +0.17/+0.16 dB，靠互补与相乘融合才显著
- [[Light-MambaIR 时频感知稀疏状态空间统一复原]] — Mamba 四向扫描后用 top-k 动态稀疏剪冗余（FLOPs −31.81% 还涨点），并行挂 Haar 小波支路（DACGB 用低频出系数调制三方向高频）补 SSM 缺的局部细节，通道拆分 + shuffle 融合，编码器末端用可学习 prompt 做退化语义；五任务一体化比 MoCE-IR 平均 +1.83 dB，参数仅 AirNet 的 12.5%，Jetson TensorRT 0.15 s
- [[PDRNet 渐进式双注意力残差网络]] — HFSM 出粗显著图 + 5 个 DRM 自深到浅只学残差（前/背景双注意力挖漏检与多余），式(13) 逐级相加而非融合以免稀释深层定位；48 FPS，残差连接贡献最大（掉约 1% 加权 F），并澄清 progressive = 逐级串联学残差
- [[WWE-UIE 小波与白平衡的水下图像增强]] — 不靠 Transformer 靠先验：Gray-World 白平衡做对数域去均值 + 逐通道 γ 可学习融合（不新增估计分支），WEB 用固定 Haar 四子带拼接后 1×1 压回、**省掉 IDWT**，SGFB 用 Sobel 幅值 + Sigmoid 出像素级门控、标量 α 粗控边界；0.734M / 6.25G / 7.6ms 在 UIEB 24.32dB·0.9196 全面前二，Color-Check7 CIEDE2000 10.10 最低；消融：去梯度分支 −0.42dB 掉最多，WGSRB 里必须先 WEB 后 SGFB，损失端 L_HSV/L_CIELab 反而不如只用 Charbonnier
- [[WINE 小波引导的GAN反演与编辑]] — WACV'25：证明 $L_1/L_2$ 在小波域是四子带等权，而实测 LL 误差是高频的 30 倍，于是提出只算高通、K=3 级分解的小波损失 + 绕开生成器卷积、直接调制 SWAGAN 小波系数的小波融合；CelebA-HQ 反演 $L_2$ 0.011（StyleRes 0.018）、高频 $L_{1,wave}$ 0.230（0.301）；消融显示只换 SWAGAN 几乎无收益，小波损失+融合缺一即有鬼影
- [[Wave-ViT 小波可逆下采样的多尺度ViT]] — ECCV'22：把多尺度 ViT 里对 K/V 的平均池化下采样换成 **DWT→3×3 Conv→IDWT** 的可逆下采样（Haar 四子带按通道拼、无损），再把 IDWT 支路当「扩了感受野的局部增强」与注意力输出 concat；Wave-ViT-S 19.8M/4.3G 拿 82.7% Top-1（PVTv2-B2 25.4M/4.0G 82.0%），COCO 小目标 AP_S 29.2 vs 27.4，ADE20K UPerNet 49.6/51.5 mIoU（比 Twins-SVT-S/Swin-S 高 2.5/2.0）；消融关键：池化换 DWT +0.5、再加 IDWT +0.2，参数几乎不变——但 Q 未下采样，仍是 O(n²) 复杂度
- [[CAUWT 内容自适应展开小波 Transformer 高光谱超分]] — 深度展开做 HSI-SR：PP 每阶段按当前重建结果预测 μ/η/γ 三个标量，GUM 用卷积/反卷积替代 Kronecker 退化矩阵，先验网络 WAT 用 DWT/IDWT 当上下采样 + CA∥MSA 并联；CAVE R=4 上比 MoGDCN/3DTNet 高 0.47/0.14 dB 而 GFLOPs 仅 6.2%/4.1%；消融：拆 DWT 掉 0.31 dB 最大、拆 PP 仅 0.17 dB、拆 MSA 掉 0.53 dB；I=3 只多 0.04 dB 却多 11.82M 参数，故取 I=2
- [[DocWaveDiff 小波U-Net与扩散的文档图像预测精炼]] — WACV'26：predict-and-refine 的**两支都换成小波 U-Net**（Haar DWT/IDWT 替池化与转置卷积），Early Predictor 只吃低频出初版、Denoiser Refiner 用 DDIM 式确定性反向链预测**高频残差**再相加，FST 频域分离损失（β0=2、β1=0.5 沿用 DocDiff），8.2M 参数；EnsExam 擦除 SOTA（PSNR 40.37 patch 级 / 39.54 整图），TDD 去模糊 LPIPS 0.0211·SSIM 0.9733 最优但 PSNR 26.28 次于 DocRes 的 27.35；消融很诚实：擦除任务只有 mask 是命门（去掉 PSNR 39.54→27.22），**拆掉 Refiner 几乎不掉点**；去模糊里小波（−1.65 dB）与注意力（−3.84 dB）才关键，去 Refiner PSNR 反升 27.09 而 LPIPS 恶化到 0.0447（感知–失真权衡）
- [[ConverseNet 反向卷积算子与图像复原]] — ICCV'25（南大 + 港理工 + OPPO）：指出转置卷积只是「插零上采样 + 标准卷积」、并非卷积的数学逆，首次提出 **Converse2D**——把「从 Y=(X⊗K)↓s 反解 X」写成带二次正则的最小二乘，圆形边界假设下推出 **FFT 闭式解（式 6）**，单步非迭代、支持任意通道与 s 倍上采样；配 LayerNorm + 1×1 Conv（补跨通道，因算子是 depthwise）+ GELU + 残差成类 Transformer 的 Converse Block，替换 DnCNN/SRResNet/USRNet 得三变体。实现四要素消融：Softmax 核初始化 > 高斯 > 均匀（30.31→30.60→30.70）、5×5 是精度/复杂度折中（7×7 只 +0.01dB）、circular padding 最好且**模式比尺寸重要**、λ=Sigmoid(b−9)+ε 逐通道可学、X₀=Interp(Y,s) 明显优于 0。去噪 σ=25 Set12/BSD68 **30.70/29.36** 一致超 Conv-/ConvT-DnCNN（30.64/30.61）；×4 超分与 SRResNet 系**打平不超越**（作者定调「可替换而不掉点」）；去模糊优势最大：盲设定 ConverseNet 27.31 vs ConvNet 23.98（**+3.33dB**），非盲 Converse-USRNet 34.62 vs 34.33，关键在**特征域**而非图像域、且能在特征层直接条件化模糊核。局限：只验算子有效性用简化设置、闭式解依赖圆形边界、只做 depthwise、未报同口径耗时、论文 §5 说 5×5 而 released 去噪代码实为 7×7/padding6（见代码笔记）

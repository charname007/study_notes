# 读论文 索引

## 论文笔记

- [[TPWGAN 小波域判别器引导的场景文本超分]] — IVC 2025：不改主干、只改「监督放在哪」——生成器加平稳小波（SWT）四子带加权 $L_1$（$\lambda_{LL}$=0.1、$\lambda_{LH/HL}$=0.01、$\lambda_{HH}$=0.05），判别器丢掉 RGB 图、改看「三支高频子带 ⊗ 二值文本掩码」的 4 通道输入 + CBAM 式空间注意力，Softplus 对抗损失；TextZoom PSNR 21.70 / SSIM 0.7965 / ASTER 64.4%，超过基线 TATT（21.52/0.7930/63.6）与 DPMN（21.49/63.9），但 CRNN 53.1 仍输 DPMN 53.2、CUTE80 输 TSRN；消融：小波损失是便宜稳定的一档（Easy ACC 76.7→78.51），对抗在 Hard 最猛（+1.6），**掩码贡献最小甚至 Medium PSNR 微降**，且不做注意力直接 concat 掩码反而更差（Hard 44.9 < 45.6）；局限：字/背景边界模糊时小波监督失效
- [[C3-STISR 三重线索引导的场景文本超分]] — arXiv'22（复旦 + 字节，ICME 前身线）：诊断出「只用识别器概率分布」的两个硬伤——模态鸿沟（PD vs 像素级任务）与不准确（LR/HR 识别率仅 26.8%/72.4%）；于是把线索扩成三条：识别 PD、**把识别串渲染成黑白字形图**当视觉线索、**字符级双向 cloze LM（SRN）**纠错当语言线索，各自投影成 $C'\times N$ 像素特征后 DSTA 去噪、门控融合成 $h_t$ 逐层灌进 5 个 TSRN block；TextZoom CRNN avg **53.7**（前最佳 TG 48.9，+4.8）、ASTER 64.1、PSNR 21.51/SSIM 0.7721；消融：deformable 对齐补偿贡献最大（49.4→51.7），MST +2.6、DSTA +2.0；**但三线索的识别率增益为零**（rec+ling 已 53.7，加 vis 仍是 53.7，只在 PSNR 上 +0.23），且 SSIM 反而低于 PCAN（77.53）
- [[LWTformer 可学习小波变换的古汉字图像修复]] — 把 2D-DWT 做成可学习下采样（WaveDown，可学习低通/高通核拆出轮廓 + 水平/垂直/对角三支高频），配 SEA 空间门控（MDTA 增量改进）与 WACGA 子带方向加权（Prewitt/Laplacian 类核）；甲骨文与 WSC41K 四项指标全 SOTA，轻量版 12.44M 参数打赢 50M 级 LoFormer-L；消融：WACGA 贡献最大 +0.225 dB，去掉感知损失 PSNR 反而更高
- [[Restormer 高效高分辨率图像修复 Transformer]] — Transformer 通道维注意力（MDTA/GDFN），17 个 benchmark SOTA

- [[AdaptIR 自适应频率增强的一体化图像复原]] — 一体化五任务一次训练：动态卷积核频谱分组调制（AFEM）+ 级联 Haar 小波扩感受野（RFEM）+ 无注意力主干；比 AdaIR 平均 +0.55 dB 且参数少 48%、推理快 2×；消融：RFEM 贡献最大 +2.99 dB，小波换傅里叶掉 3.24 dB
- [[PAGRN 渐进式注意力引导循环网络]] — 渐进式注意力（SA+CA 串联，高层指导低层）+ 多路循环反馈，6 个数据集显著性检测 SOTA；已补精读要点：符号 csa 拆解、式(6) 维度坑、多路径在式(9) 的三处体现、前向 vs 反向澄清
- [[SVTR 场景文本识别]] — 单一视觉模型做 STR：渐进重叠 patch embedding + 局部/全局混合块 + 只压高度的 merging，英文打平 VLM、中文 +5.4~9.6%
- [[FlashAttention 精确注意力与IO感知]] — 用 tiling + 重算把 N×N 注意力矩阵挡在 HBM 之外：FLOPs 更多却快 2–4×、显存 O(N²)→O(N)，且完全精确
- [[感知损失 实时风格迁移与超分辨率]] — 用冻结 VGG-16 的 feature 差 + Gram 矩阵差当损失，把 Gatys 的优化式风格迁移蒸馏成前向网络：快三个数量级（512×512 达 20 FPS），超分上细节更好但 PSNR 更低
- [[ASTER 注意力场景文本识别器]] — TPS/STN 柔性矫正（20 个控制点、固定输出端预测输入端）+ 双向注意力 Seq2Seq 解码；无控制点标注的端到端训练，SVTP +4.7%、CUTE +3.1%，还能反哺检测框（HMean 0.626→0.768）
- [[MORAN 多目标矫正注意力场景文本识别]] — MORN 逐块预测偏移场（33 锚点 + 双线性展开，无几何约束、无固定点数限制）+ ASRN 加性注意力解码；训练期技巧 fractional pickup 加宽视野、三阶段课程学习；IIIT5K 91.2%、CUTE80 77.4%
- [[VTCTSRN 视觉文本线索迁移的场景文本超分]] — ICME'25：识别器渲染的原型图当先验，图侧可变形采样取 K/V、原型侧 DCN 当 Q，再做跨注意力 + 门控融合；DA-SRB 用 attention map 调制 + DSConv 提笔画；TextZoom CRNN 63.0%（前最佳 59.0），去掉原型掉 10.5 分
- [[PAN 渐进式注意力网络与视觉属性预测]] — 在 CNN 多个中间层反复施加注意力（乘 α 后不求和、直接传给下一层卷积），配硬注意力似然边际化（免 REINFORCE）+ 局部上下文：MREF TPR 13.83→62.31，MBG 尺度跨度从 19.8 收到 4.6
- [[DTWSR 扩散Transformer建模多级小波谱的单图超分]] — 三星 SRCX：把整条扩散去噪链搬进小波谱域（每个采样步 MDWT→谱域去噪→IMDWT），金字塔 tokenization（$p^j=p_{min}2^{J-j}$，token 1040→704）+ 4D 位置编码 + 双解码器（LEDec 管 LF 主体、HDDec 管多级 HF 与 LF 残差，配 $M_{low}/M_{high}$ 两个互斥掩码）；8× 人脸 Cons. 0.50 / Deg. 53.85 / FID 56.77 三项最优（PSNR 24.09 不及 WFEN 的 25.53，但那版输出过平滑），RealSR 上 MUSIQ 64.04 最高；消融关键：双解码器单独拆开 Cons. 反而变差（2.35），必须配 LF 残差才回到 0.549，再加 $M_{high}$ 才到 0.503；切断 HF 子带交互 FID 56.77→61.67，印证核心动机
- [[PFT 渐进聚焦 Transformer 单图超分]] — 相邻层注意力图做 Hadamard 乘积并逐行归一化（连乘自然稀疏），再把结果当 0/1 索引**先选后算**跳过相似度计算：Urban100 ×4 +0.36dB 且 FLOPs −27.7%，撑起 32×32 大窗口；消融证明"继承买精度、聚焦买速度"
- [[HDW-SR 小波高频引导扩散的单图超分]] — SRCX 2026（CVPR 2026）：残差扩散 + **Haar 小波当上下采样**替换 U-Net 池化，用 PreSR 的高频子带（LH/HL/HH）当 K/V、与噪声图低频做稀疏交叉注意力（DFA，继承 PFT 的层间索引）；DTB 把 Top-k 换成 Otsu 类间方差定 $k^*$；DIV2K/RealSR/DrealSR 上 LPIPS、DISTS、MUSIQ 基本全胜，但 **PSNR 略低于 ResShift**；消融：去掉高频引导 −3.56 dB、先验换成 HA-Net 自身 −1.32 dB、DWT 换回 CNN −0.55 dB；DTB 同时省 22% FLOPs
- [[StarIR 空间-频率融合的卷积图像复原]] — 纯卷积 encoder-decoder：FMB（8×8 窗口 FFT + 可学习频响）⊗ SMB（空间注意力）做 star 相乘融合 + CMU 通道调制；21 数据集 6 类单退化 SOTA，五任务一体化平均 +0.96 dB，CDD-11 三退化 +2.89 dB 且参数少 41%；消融显示 SMB/FMB 单加仅 +0.17/+0.16 dB，靠互补与相乘融合才显著
- [[Light-MambaIR 时频感知稀疏状态空间统一复原]] — Mamba 四向扫描后用 top-k 动态稀疏剪冗余（FLOPs −31.81% 还涨点），并行挂 Haar 小波支路（DACGB 用低频出系数调制三方向高频）补 SSM 缺的局部细节，通道拆分 + shuffle 融合，编码器末端用可学习 prompt 做退化语义；五任务一体化比 MoCE-IR 平均 +1.83 dB，参数仅 AirNet 的 12.5%，Jetson TensorRT 0.15 s
- [[PDRNet 渐进式双注意力残差网络]] — HFSM 出粗显著图 + 5 个 DRM 自深到浅只学残差（前/背景双注意力挖漏检与多余），式(13) 逐级相加而非融合以免稀释深层定位；48 FPS，残差连接贡献最大（掉约 1% 加权 F），并澄清 progressive = 逐级串联学残差
- [[WWE-UIE 小波与白平衡的水下图像增强]] — 不靠 Transformer 靠先验：Gray-World 白平衡做对数域去均值 + 逐通道 γ 可学习融合（不新增估计分支），WEB 用固定 Haar 四子带拼接后 1×1 压回、**省掉 IDWT**，SGFB 用 Sobel 幅值 + Sigmoid 出像素级门控、标量 α 粗控边界；0.734M / 6.25G / 7.6ms 在 UIEB 24.32dB·0.9196 全面前二，Color-Check7 CIEDE2000 10.10 最低；消融：去梯度分支 −0.42dB 掉最多，WGSRB 里必须先 WEB 后 SGFB，损失端 L_HSV/L_CIELab 反而不如只用 Charbonnier
- [[WINE 小波引导的GAN反演与编辑]] — WACV'25：证明 $L_1/L_2$ 在小波域是四子带等权，而实测 LL 误差是高频的 30 倍，于是提出只算高通、K=3 级分解的小波损失 + 绕开生成器卷积、直接调制 SWAGAN 小波系数的小波融合；CelebA-HQ 反演 $L_2$ 0.011（StyleRes 0.018）、高频 $L_{1,wave}$ 0.230（0.301）；消融显示只换 SWAGAN 几乎无收益，小波损失+融合缺一即有鬼影
- [[Wave-ViT 小波可逆下采样的多尺度ViT]] — ECCV'22：把多尺度 ViT 里对 K/V 的平均池化下采样换成 **DWT→3×3 Conv→IDWT** 的可逆下采样（Haar 四子带按通道拼、无损），再把 IDWT 支路当「扩了感受野的局部增强」与注意力输出 concat；Wave-ViT-S 19.8M/4.3G 拿 82.7% Top-1（PVTv2-B2 25.4M/4.0G 82.0%），COCO 小目标 AP_S 29.2 vs 27.4，ADE20K UPerNet 49.6/51.5 mIoU（比 Twins-SVT-S/Swin-S 高 2.5/2.0）；消融关键：池化换 DWT +0.5、再加 IDWT +0.2，参数几乎不变——但 Q 未下采样，仍是 O(n²) 复杂度
- [[CAUWT 内容自适应展开小波 Transformer 高光谱超分]] — 深度展开做 HSI-SR：PP 每阶段按当前重建结果预测 μ/η/γ 三个标量，GUM 用卷积/反卷积替代 Kronecker 退化矩阵，先验网络 WAT 用 DWT/IDWT 当上下采样 + CA∥MSA 并联；CAVE R=4 上比 MoGDCN/3DTNet 高 0.47/0.14 dB 而 GFLOPs 仅 6.2%/4.1%；消融：拆 DWT 掉 0.31 dB 最大、拆 PP 仅 0.17 dB、拆 MSA 掉 0.53 dB；I=3 只多 0.04 dB 却多 11.82M 参数，故取 I=2
- [[DocWaveDiff 小波U-Net与扩散的文档图像预测精炼]] — WACV'26：predict-and-refine 的**两支都换成小波 U-Net**（Haar DWT/IDWT 替池化与转置卷积），Early Predictor 只吃低频出初版、Denoiser Refiner 用 DDIM 式确定性反向链预测**高频残差**再相加，FST 频域分离损失（β0=2、β1=0.5 沿用 DocDiff），8.2M 参数；EnsExam 擦除 SOTA（PSNR 40.37 patch 级 / 39.54 整图），TDD 去模糊 LPIPS 0.0211·SSIM 0.9733 最优但 PSNR 26.28 次于 DocRes 的 27.35；消融很诚实：擦除任务只有 mask 是命门（去掉 PSNR 39.54→27.22），**拆掉 Refiner 几乎不掉点**；去模糊里小波（−1.65 dB）与注意力（−3.84 dB）才关键，去 Refiner PSNR 反升 27.09 而 LPIPS 恶化到 0.0447（感知–失真权衡）

- [[PAGRN 渐进式注意力引导循环网络]] — 渐进式注意力（SA+CA 串联，高层指导低层）+ 多路循环反馈，6 个数据集显著性检测 SOTA；已补精读要点：符号 csa 拆解、式(6) 维度坑、多路径在式(9) 的三处体现、前向 vs 反向澄清
- [[SVTR 场景文本识别]] — 单一视觉模型做 STR：渐进重叠 patch embedding + 局部/全局混合块 + 只压高度的 merging，英文打平 VLM、中文 +5.4~9.6%
- [[FlashAttention 精确注意力与IO感知]] — 用 tiling + 重算把 N×N 注意力矩阵挡在 HBM 之外：FLOPs 更多却快 2–4×、显存 O(N²)→O(N)，且完全精确
- [[感知损失 实时风格迁移与超分辨率]] — 用冻结 VGG-16 的 feature 差 + Gram 矩阵差当损失，把 Gatys 的优化式风格迁移蒸馏成前向网络：快三个数量级（512×512 达 20 FPS），超分上细节更好但 PSNR 更低
- [[ASTER 注意力场景文本识别器]] — TPS/STN 柔性矫正（20 个控制点、固定输出端预测输入端）+ 双向注意力 Seq2Seq 解码；无控制点标注的端到端训练，SVTP +4.7%、CUTE +3.1%，还能反哺检测框（HMean 0.626→0.768）
- [[MORAN 多目标矫正注意力场景文本识别]] — MORN 逐块预测偏移场（33 锚点 + 双线性展开，无几何约束、无固定点数限制）+ ASRN 加性注意力解码；训练期技巧 fractional pickup 加宽视野、三阶段课程学习；IIIT5K 91.2%、CUTE80 77.4%
- [[VTCTSRN 视觉文本线索迁移的场景文本超分]] — ICME'25：识别器渲染的原型图当先验，图侧可变形采样取 K/V、原型侧 DCN 当 Q，再做跨注意力 + 门控融合；DA-SRB 用 attention map 调制 + DSConv 提笔画；TextZoom CRNN 63.0%（前最佳 59.0），去掉原型掉 10.5 分
- [[PAN 渐进式注意力网络与视觉属性预测]] — 在 CNN 多个中间层反复施加注意力（乘 α 后不求和、直接传给下一层卷积），配硬注意力似然边际化（免 REINFORCE）+ 局部上下文：MREF TPR 13.83→62.31，MBG 尺度跨度从 19.8 收到 4.6
- [[PFT 渐进聚焦 Transformer 单图超分]] — 相邻层注意力图做 Hadamard 乘积并逐行归一化（连乘自然稀疏），再把结果当 0/1 索引**先选后算**跳过相似度计算：Urban100 ×4 +0.36dB 且 FLOPs −27.7%，撑起 32×32 大窗口；消融证明"继承买精度、聚焦买速度"
- [[StarIR 空间-频率融合的卷积图像复原]] — 纯卷积 encoder-decoder：FMB（8×8 窗口 FFT + 可学习频响）⊗ SMB（空间注意力）做 star 相乘融合 + CMU 通道调制；21 数据集 6 类单退化 SOTA，五任务一体化平均 +0.96 dB，CDD-11 三退化 +2.89 dB 且参数少 41%；消融显示 SMB/FMB 单加仅 +0.17/+0.16 dB，靠互补与相乘融合才显著
- [[PDRNet 渐进式双注意力残差网络]] — HFSM 出粗显著图 + 5 个 DRM 自深到浅只学残差（前/背景双注意力挖漏检与多余），式(13) 逐级相加而非融合以免稀释深层定位；48 FPS，残差连接贡献最大（掉约 1% 加权 F），并澄清 progressive = 逐级串联学残差

# obsidian-study-notes Skill

## 是什么

一个自定义的 DSH Skill（学习笔记整理员），用于把论文、代码、聊天灵感等内容经 AI 提炼后自动写入本 Obsidian 库（`E:\学习笔记`），自动完成分类、贴标签、建双链、维护目录索引和 git 提交。

## 触发方式

对 DSH 说以下任意一句即可触发：
- 「整理一下这个」
- 「存笔记」
- 「记到 Obsidian」
- 「放进学习笔记」
- 「把刚才聊的存一下」
- 「重新整理笔记库」（全库诊断 + 重整）

## 核心规则

### 分类目录

| 目录 | 内容 | 类型标签 |
|---|---|---|
| `读论文/` | 论文阅读笔记 | #论文 |
| `深度学习/` | 概念理解、知识点 | #概念 |
| `代码细节笔记/` | 代码原理、踩坑 | #代码 |
| `聊天随想/` | 对话灵感、随想 | #随想 |
| `AI工具/` | AI 工具、Skill、提示词 | #工具 |
| `inbox/` | 拿不准归属的缓冲 | — |

### 标签体系

- 每篇笔记 = 1 个类型标签 + 1~3 个主题标签
- 同义词复用已有标签，保持全库一致
- 标签同时出现在 frontmatter `tags:` 字段和正文末尾

### 自动双链

写入前扫描库内已有笔记，自动建立 `[[双链]]`，并在「相关笔记」小节列出 2~5 条。

### 防重复

写入前 grep 查重，同主题笔记会让用户选择**合并**或**另建并互链**。

### 新建目录需批准

Agent 只能提议新目录，用户同意后才创建。

### 每目录 _索引.md

每个内容目录维护一个 `_索引.md`（MOC），按主题分组列出该目录所有笔记。

### git 自动提交

每次写入后自动 `git add -A && git commit -m "note: 新增/更新 <笔记名>"`。

## 笔记模板

四种类型各有模板：
- **论文**：一句话总结 → 核心问题 → 关键方法 → 结论与局限 → 我的疑问 → 关键摘录 → 相关笔记
- **概念**：是什么 → 为什么需要 → 怎么做/关键细节 → 常见误区 → 相关笔记
- **代码**：场景 → 关键点 → 代码片段 → 相关笔记
- **随想**：提炼想法 → 待深究 → 相关笔记

## 全库重整模式

两阶段：
1. **诊断报告**（只读）：检查分类不当、孤立笔记、命名不规范、标签不一致、frontmatter 缺失、杂物
2. **执行**（用户确认后）：批量移动/重命名/补 frontmatter/统一标签，全程可 git 回滚

## 防幻觉约束

- 所有事实必须来自原材料，禁止编造
- 摘录必须逐字引用
- 信息不足标注 `⚠️ 信息不足`
